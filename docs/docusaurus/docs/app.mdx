## The sidebar {#sidebar}

Projects group tasks by repository, with tasks waiting on you first. A row shows the step strip, coloured by stage, and live agent activity; amber means it needs you. Its toggle opens the task lists Claude Code, Codex and OpenCode report, and their helpers.

- Right-click a project to rename, recolor or hide it; right-click a task to rename, archive or delete it.
- The foot shows [plan limits](agents/native.mdx#plan-limits) or today's cost. With [machines](machines.mdx), the head switches computers.
- **View options** filters names, groups and row sizes. **Last activity** keeps tasks changed in the last 24 h, 3 d or 7 d; working and open tasks stay visible.
- Drag past the narrowest width to collapse the sidebar into a rail of Home, Artifacts, waiting and running tasks, plan limits and Settings. Pull the rail outward to reopen it.

**⌘K** searches actions, projects, tasks and files; **⌘P** opens a file in the current task. Use Ctrl instead of ⌘ on Windows and Linux.

## Answering questions {#questions}

<Screenshot name="question" alt="A Plan question in Your turn: the recommended choice open with its diagram, the other folded to one line, and your own answer below" />

**Your turn** shows one question; its numbered strip lets you answer in any order. Where choices have facts, the recommended one is open and the others fold to one line. A question about a screen shows that screen in the card. Answers reach your agent at once and never approve the Plan or the change.

<details>

| Key | Action |
| --- | --- |

| **T** | Write your own answer, then **Send** |

</details>

## Documents and your agent {#comments-and-artifacts}

<CardGroup cols={2}>
  <Card title="Files" icon="file-text">Every document, artifact, review and record, plus **Review the code** and **View changes**. **Records** opens `records/`, `evidence/` and `agents/`.</Card>
  <Card title="Reader" icon="app-window">A whole document, with **On this page** and **Copy document**. Step documents end with **For agents**.</Card>
</CardGroup>

**Copy as Markdown** keeps Mermaid and local picture names; **Copy formatted** includes PNG pictures. Working artifacts are compact entries in **Files**; **Open full size** opens the whole page.

Select a passage, a code line or a spot on an artifact and choose **Ask agent**. Conversation opens an editable draft with the selection and its revision; send it through your agent's own input, or copy it when that input is not supported. A request never approves a Plan, changes approved scope or settles the final approval.

## Code review {#code-review}

<Screenshot name="verify-review" alt="The code review: the changed files by slice beside the diff, with why each file changed" />

Open **Changes** in the header or **Review the code** in Verify or Files. Choose one file or all files, **Unified / Split** diffs, or **Full file › Version** for an exact revision. **Viewed** records your reading progress; **All viewed** and **Clear** apply to every file. **Exit** returns to where you came from; while your approval waits it reads **Finish code review**.

## What it costs {#cost}

**Cost** in the task header reads local logs: Copilot's recorded AI-credit value where available, otherwise estimates at verified API prices. Credit value is not money billed on top; partial amounts are labelled, and unknown values show a dash. Amounts stay hidden until you open it. **Usage history** opens **Settings › Usage**.

## Agent runs {#agent-runs}

When you start a task or the build, choose where the agent runs:

<Tabs groupId="where">
  <Tab value="app" label="In the App">Recommended. Pick the agent, model, effort and branch. You answer in **Conversation**.</Tab>
  <Tab value="agent" label="In my own agent">Your terminal, IDE or agent app. Ask it in your own words, or copy the prepared prompt. It asks in its own chat; you can still approve a ready Plan and the finished change in the App.</Tab>
</Tabs>

Closing the sidebar keeps the run. The agent's menu has **Interrupt** (**Esc**), **Stop session** and **Move to my own agent…**; **Resume** returns.

**Conversation** folds finished turns to one line; **Terminal** shows the agent's own program. Below the message box sit activity, model, effort, [permissions](agents/native.mdx#permission-modes), pacing and context; each opens its own details. Paste or drop files in either view.

<Tip>**Messages while working** steers your agent at its next step where it supports that, and otherwise queues without interrupting. Choose **Queue until the turn ends** to wait instead. Thinking can be hidden, collapsed or expanded under **Agent controls › Appearance…**.</Tip>

## In Claude Code {#in-claude-code}

A band above your prompt says when this task or another one needs you; `/task-pane` adds the steps, build progress and every task that needs you, runs or has an open pull request.
