## Start a task {#start}

Ask in plain words:

```text
Using QualityLayer, plan a CSV export.
```

If you ask your agent to plan without naming QualityLayer, it offers QualityLayer once and you pick **Yes** or **No**. An ordinary coding request never starts a workflow.

<Tip>To turn the offer off, clear **Offer QualityLayer** in [Settings › Workflow](reference/settings.mdx#workflow), or run `qualitylayer settings set offerWorkflow false`.</Tip>

## Choose where you answer and approve {#where}

Your first task started in your agent asks once, in the agent's own picker:

<CardGroup cols={3}>
  <Card title="Here in your agent" icon="square-terminal">Questions and approvals in its chat, such as **Here in Claude Code**.</Card>
  <Card title="In the App" icon="app-window">Questions and approvals in the App.</Card>
  <Card title="Questions here" icon="message-square">Questions in your agent, approvals in the App.</Card>
</CardGroup>

Your pick is saved and not asked again. Change it in **Settings › Workflow** (**Answer questions in** and **Approve in**), or by command (`app` sends it to the App, `terminal` keeps it in your agent):

```sh
qualitylayer settings set answers terminal
qualitylayer settings set approvals terminal
qualitylayer task set answers=terminal approvals=app   # this task only
```

The two rows also allow questions in the App with approvals in your agent.

<Note>Tasks you start in the App always answer in the App.</Note>

## What you see in your agent {#what-you-see}

<Steps>
  <Step title="Questions">In Plan, in the agent's own picker.</Step>
  <Step title="The Plan">A short summary and the path of the full file, any **Your call** to settle, then **Approve Plan**, **Give feedback** or **Show the Plan**.</Step>
  <Step title="Where to build">**Build here, from the Plan** (compact, then say "build here"), **Keep this conversation** or **Another session or agent**.</Step>
  <Step title="Verify">The final approval, once every point is proven.</Step>
</Steps>

Only your own pick or words count as an answer or an approval. The Plan in a fictional task:

```text
Plan ready: Add a CSV export to the Orders page
Adds an Export button that downloads the rows you filtered.
Full text: docs/plans/csv-export/01-plan.md

  Approve Plan
  Give feedback
  Show the Plan
```

## Agents and pickers {#pickers}

| Agent | How you answer |
| --- | --- |
| Claude Code, Codex, Pi, OpenCode, Grok, Antigravity, GitHub Copilot | The agent's own picker |
| Cursor | Numbered choices in the chat. Type the number or your own words. |

Setup turns on Codex's question picker and lets Grok's questions wait for you instead of expiring. If you turned the picker off in Codex, it uses numbered choices. `qualitylayer doctor` shows whether each installed agent's picker is ready.

## Use the App anyway {#app}

A task that answers in your agent still shows in the App. Its open question appears read-only, with **Answer here instead** if you would rather answer there.
