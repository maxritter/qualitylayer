Any coding agent that runs shell commands, including local models, can run the same workflow through the `qualitylayer` command. [Supported agents](native.mdx) also get the App's conversation view and session controls.

![Another agent with the qualitylayer command and a prompt from the App follows the same steps](pathname:///img/diagrams/agents-other-light.svg)
![Another agent with the qualitylayer command and a prompt from the App follows the same steps](pathname:///img/diagrams/agents-other-dark.svg)

## Start a task {#start}

<Steps>
  <Step title="Check the command">Have your agent run `qualitylayer help`. Nothing listed? Run `qualitylayer doctor`.</Step>
  <Step title="Ask in plain words">"Using QualityLayer, plan a CSV export without the App."</Step>
  <Step title="Continue in your agent">It follows the same workflow, asks with [numbered choices](../work-in-your-agent.mdx#pickers) and saves the documents on disk.</Step>
</Steps>

<Note>Results depend on the model: it has to call tools reliably over many turns.</Note>

## Plan with one agent, build with another {#mix}

![Plan with Claude Code, approve the Plan, build with another agent, then the same checks and your approval](pathname:///img/diagrams/agents-mix-light.svg)
![Plan with Claude Code, approve the Plan, build with another agent, then the same checks and your approval](pathname:///img/diagrams/agents-mix-dark.svg)

On **Start the build**, choose **In my own agent**, then ask your agent in the project to continue the approved task, or paste the prepared request. It follows Implement and Verify until your final approval.<span id="app-start"></span>

## What changes {#differences}

| | Supported agents | Any other agent |
| --- | --- | --- |
| Setup | Done when you install | Ask in your own words |
| Model and effort | Set in QualityLayer | Set in your agent |
| Building | One session builds the slices; it can use its agent's own subagents | One session builds the slices with its own tools |
| Sessions | The App's **Conversation** and session controls | Your agent's own window and controls |
| Cost panel | Per step, when the agent's records hold token counts | Not shown |

<details>
<summary>For the agent's author</summary>

The prompt asks the agent to run `qualitylayer next --json`, follow the reply and read the files it names, until the reply says done or stop.

To keep working after a question, run `qualitylayer wait --until-event` in the background. It returns on an answer, review result or finished check, or after 30 minutes.

Checks run on a clean copy of the commit, without `.venv` or `node_modules`. Use `$QL_REPO_ROOT` to reach your folder, for example `"$QL_REPO_ROOT/.venv/bin/python" -m pytest`.

</details>
