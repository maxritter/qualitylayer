Settings

Open Settings with the gear at the bottom of the sidebar; its search finds any setting. Changes save at once for this computer.

Tip: Every setting also works by command, qualitylayer settings set <key> <value>, or by asking your agent. The command reference lists the few that stay in the App.

Each review row lists the model every installed agent uses for it; click a model to change it in Models.

Your instructions

Write up to 12,000 characters in ~/.qualitylayer/instructions.md. Agents, helpers and reviewers read it each step; documents never copy it. Headings such as ## Plan and ## Implement limit lines to that step; a checkbox (- [ ]) under one is a step check. Instructions cannot approve a gate.

Step checks

A step check is a checkbox line under a step's heading. The agent must do it, then record it done or skipped with a reason.

## Verify
- [ ] run: `wizcli dir scan --path .`
- [ ] Review auth changes with the threat-model skill
- Mention Wiz findings in the pull request.
Line What happens
- [ ] run: … under Implement or Verify A Project check: the Plan names it, approving the Plan covers running it, and Verify records its result
- [ ] with other words The agent does it its own way, with a skill, an MCP tool or by hand, and records a note or a reason
- a plain bullet Guidance only

Add one in Your instructions › Steps, ask your agent (“Add a Wiz scan to Verify's step checks”), or run qualitylayer instructions add verify "<line>". A task keeps the checks it started with; skipped ones stay in its record. Commands use the logins already on your computer.

Independent review

On: a separate agent checks each Done means point in Verify. Helpers: This session in Models keeps review in the lead session, marked as not independent. Off: Verify shows Independent review as skipped. Models sets the model each agent reviews on.

Second opinion

On adds a read-only review by another agent for risky Plans and changes. Risk includes sign-in, secrets, outside input, or a Plan or slice marked risky. The Workflow row shows which agent reviews which. In Models you pick, for each agent, the other installed agent that reviews its work and the model it uses. The default is the first agent here from another model family, so GPT reviews Claude and Claude reviews GPT. If the chosen agent is not installed or not signed in, the default reviews instead. Your agent can set it too: qualitylayer settings set secondOpinion.reviewers.claude-code '{"agent":"codex","model":"gpt-6.1-sol"}'.

Note: A feature can also take up to two extra planners, each an agent, model and effort, chosen in New task or with qualitylayer task start "<request>" --planners agent:model[:effort],…. They review its Plan instead of the second opinion, and each is an extra paid planning run.
How the default reviewer is picked
  • Pi and OpenCode count by the model they run; Cursor's Auto never counts as another family.
  • Agents that enforce read-only come first, then Claude Code, Codex, Grok, Pi, OpenCode, Cursor, Antigravity, GitHub Copilot. Cursor and Antigravity review a disposable copy.
  • When every agent here runs the same family, a fresh session reviews on its agent’s second-opinion model. Reviewed by in the Plan names who read it.

Security scans

Scan each change runs the security scans in Verify and the secrets scan after each agent turn. Off: Verify's Security scans lane says Off; the reviews still run.

Dependency advisories: osv.dev sends the package names and versions of a changed lockfile to Google's open vulnerability database; your code stays here. Local copy downloads that database (about 250 MB for npm and PyPI) the first time a project needs it, and nothing leaves this computer.

Agents

  • The model button on the row, or ⋯ › Models, opens Models on that agent.
  • Install… opens the vendor's page; QualityLayer never runs an installer.

Models

Pick an agent by its mark. A fresh setup recommends Opus in Claude Code and GPT-6.2 Astra in Codex and Pi for planning and reviews. OpenCode starts on its own settings and recommends Astra for reviews. Saved choices still apply, and each launch can pick another model. Each group's Reset to recommended restores its own rows.

Group Rows
Plan and Implement Plan, Implement · full task, Implement · small change, Implement subagents (Codex and Claude Code) and Helpers for research, fixes, security checks and Chat work. This session keeps helper work in the lead session
Reviews Independent review: the model a fresh helper checks this agent's change on. Design review: the model a fresh helper checks this agent's designs on. Second opinion: the other installed agent that reads this agent's risky work, and its model. Each works by command too, such as qualitylayer settings set models.codex.design gpt-6.1-sol
Model list Open the selected agent’s catalog to see the models assigned to roles. Search by name or id, or choose Show all to browse. Add a model… takes an id the agent accepts. Remove puts its roles back on the recommended model

Usage

Usage display defaults to Used; Remaining changes both the App and macOS menu bar. Menu bar usage starts on.

Control What it changes
Menu bar readings Reported quota windows and daily dollars. Quota choices also select the Usage popup's rows
Daily total Optional: API spend ($) counts metered use; All usage at API prices ($) also values subscriptions for comparison

Credits stay separate in Usage; missing data makes totals partial. The task header’s Cost uses recorded Copilot AI-credit usage value where available, clearly labelled separately from API-price estimates and money billed.

Plan limits shows reported windows for Claude Code, Codex and GitHub Copilot. Visible readings refresh every five minutes; Codex and Copilot depend on their latest source records. Resume when a limit resets (on) continues stopped builds unless someone has typed since; Cancel resume in the task's agent status stops one.

What your agents used has daily charts, comparisons and model breakdowns for 7 days, 30 days or this month. Every supported agent is covered where its records provide usage; Cursor needs a local CSV import. The same money choice applies to statistics. API-price value is not your bill.

Sessions

Running now lists running agents; Stop N idle stops the idle ones, which keep their conversation. Stopping several asks for confirmation.

Setting Choices
Stop agents that sit idle Never, 2 h, 8 h (default) or a day; never one with an open question, approval, turn or helper
Who can type in a session The App and its browsers (default), or also other paired browsers
When you quit the App Agents keep running (default) or Stop agents

Machines

Work on another Linux or macOS computer, or a dev container, you reach over ssh, from this App (setup guide). Add machine takes user@host, a Mac nearby, a host from your ssh config or a running dev container; Add pairs it in one progress view, installs QualityLayer there and activates your licence key on it. It asks for the machine's password at most once and stores none. The sidebar's head then switches between This computer and each machine, with a count of what waits for you elsewhere.

A machine keeps working while this computer sleeps and reconnects by itself. A machine that is down says why and offers its fix: Try now, Pair again for a refused key, or Trust new key with the new fingerprint. Remove… also takes QualityLayer's key off the machine and its ssh config entry here, unless you clear that; tick Also release its licence to free the machine's activation. Windows machines keep their own App.

Notifications

Tell me when a task needs me enables system notifications; Play a sound with it adds sound.

Use your own connected machine or paired browser to return to your work away from this computer.

Git and editor

Tools shows whether Git and gh are signed in; without gh, no pull requests. Open files and folders in picks VS Code, Cursor, Zed, Finder or Terminal. Watch pull requests (on) wakes the task's agent on a failing check, change request or conflict, at most 3 times a day per pull request, and on people's new review comments up to 2 more times, never below 10 % of the plan left.

Automations

Send task events to a URL or a command. A browser that may only watch cannot change them. See Automations.

Memory

Pause, search or retire lessons, including Yours, the lessons about you. Manage projects controls optional Git export per repository (Project memory).

Licence

Your plan or trial, and Open billing account. To use a key you bought, choose Enter key… (during the trial too) and paste it from your billing account; Setup offers the same field. From a terminal, run qualitylayer licence activate <key>; on Windows before the command is set up, run & "$env:LOCALAPPDATA\QualityLayer\qualitylayer-cli.exe" licence activate <key> in PowerShell. Each licence key works on 5 computers, machines included; on Business, every assigned seat has its own key. On another computer shows how to move the licence. When all 5 are in use, release one under Licence keys in your billing account, run qualitylayer licence deactivate on the old computer, or write to hello@qualitylayer.dev.

About

The version, Check now and Update channel: Stable (default) or Beta, which also moves to each newer stable release (Updates).

Server

Server port is 41888 unless you change it (1024 to 65535); type one and Restart on N. In use now shows the real port, for example "41888 was taken, so it uses 41889." QUALITYLAYER_PORT overrides it for one server; qualitylayer settings set cockpit.port <port> sets it from the command line.

Tell your agent "skip security", "run the security review", "get a second opinion" or "no second opinion".
