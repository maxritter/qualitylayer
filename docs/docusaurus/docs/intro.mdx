## The three steps {#the-three-steps}

![The workflow from Plan to the pull request; you approve the Plan and the finished change, and merge](pathname:///img/diagrams/flow-pr-light.svg)
![The workflow from Plan to the pull request; you approve the Plan and the finished change, and merge](pathname:///img/diagrams/flow-pr-dark.svg)

<CardGroup cols={3}>
  <Card title="Plan" icon="network" tone="plan" href="/docs/steps/plan">Your agent reads the code, asks what only you can answer and writes the Plan. **You approve it.**</Card>
  <Card title="Implement" icon="code-xml" tone="implement" href="/docs/steps/implement">Your agent cuts the Plan into slices and builds each one test first.</Card>
  <Card title="Verify" icon="shield-check" tone="verify" href="/docs/steps/verify">Your checks run, then an agent that did not write the code checks every point. **You review and approve.**</Card>
</CardGroup>

<Tip>After you approve, your agent opens the [pull request](steps/pull-request.mdx) and fixes failing checks. You merge.</Tip>

## Kinds of task {#choose-how-to-work}

<CardGroup cols={3}>
  <Card title="Feature" icon="lightbulb">The three steps, from **Plan with QualityLayer** or an **Existing plan**.</Card>
  <Card title="Bugfix" icon="bug">The three steps; the Plan names the cause and starts with a failing test.</Card>
  <Card title="Chat" icon="message-square" href="/docs/chat">A conversation without steps. Move it into the workflow when it grows.</Card>
</CardGroup>

## Your agents {#who-it-is-for}

Claude Code, Codex, Cursor, Grok, Antigravity, Pi, OpenCode and GitHub Copilot [run natively](agents/native.mdx). Any other agent [uses the CLI](agents/other.mdx). Each keeps its own login and provider.

<Note><span id="how-it-fits-together"></span>Each task leaves `01-plan.md`, `02-implement.md` and `03-verify.md` in your repository. They stay when you uninstall ([files and privacy](reference/files.mdx#documents)).</Note>
